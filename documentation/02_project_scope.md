# Sales & Profitability Analytics --- Project Scope

## 1. Project Goal

Build an end-to-end analytics project that demonstrates real-world Data
Analyst thinking using:

-   Python
-   Pandas
-   SQL/MySQL
-   Power BI
-   Data quality analysis
-   Exploratory data analysis
-   Business reasoning

The project will intentionally contain imperfect data so that data
cleaning and validation become part of the analysis.

## 2. In Scope

### Business Analysis

-   Revenue analysis
-   Profitability analysis
-   Customer analysis
-   Product analysis
-   Regional analysis
-   Sales channel analysis
-   Discount analysis
-   Return analysis
-   Target vs actual analysis
-   Trend analysis
-   Driver analysis

### Technical Analysis

-   Data profiling
-   Missing-value analysis
-   Duplicate detection
-   Invalid-value detection
-   Outlier detection
-   Referential-integrity checks
-   Category standardization
-   Date validation
-   Derived metric validation
-   SQL aggregation
-   SQL window functions
-   Python EDA
-   Power BI modeling and reporting

## 3. Out of Scope for Version 1

The first version will not focus on:

-   Machine learning
-   Forecasting
-   Advanced predictive modeling
-   Real-time streaming
-   Complex cloud architecture
-   Highly decorative dashboard design

These may be added later if they provide genuine business value.

## 4. Analytical Tools

### Python

Primary uses:

-   Data generation
-   Data profiling
-   Data cleaning
-   Data validation
-   Exploratory analysis
-   Statistical exploration
-   Business-driver analysis

### SQL

Primary uses:

-   Data extraction
-   Aggregation
-   Joins
-   Business metrics
-   Ranking
-   Window functions
-   Time-based comparisons
-   Advanced interview questions

### Power BI

Primary uses:

-   KPI reporting
-   Trend visualization
-   Interactive slicing
-   Business-driver exploration
-   Executive communication

## 5. Project Philosophy

The project will prioritize analytical reasoning over visual complexity.

A simple dashboard with strong insights is preferred over a visually
impressive dashboard with weak business analysis.

## 6. Success Criteria

The project is successful if we can:

1.  Explain the business problem clearly.
2.  Identify and document data-quality issues.
3.  Clean and validate the data systematically.
4.  Reproduce important metrics using SQL.
5.  Perform deeper analysis using Python.
6.  Communicate the findings through Power BI.
7.  Explain the causes behind important metric movements.
8.  Recommend practical business actions.
9.  Defend the methodology in an interview.

## 7. Final Deliverables

-   Raw datasets
-   Cleaned datasets
-   Python scripts
-   SQL analysis scripts
-   Power BI dashboard
-   Data dictionary
-   Data-quality report
-   Business analysis report
-   Business recommendations
-   Interview question bank
